# Airbnb Advanced SQL Scripts

This directory contains advanced SQL queries and optimization scripts for the **ALX Airbnb Database** project.

## Files and Descriptions

- **joins_queries.sql** – Contains SQL queries using `INNER JOIN`, `LEFT JOIN`, and `FULL OUTER JOIN` to combine data between tables like users, bookings, properties, and reviews.
- **subqueries.sql** – Will include correlated and non-correlated subqueries for filtering and analysis (Task 1).
- **aggregations_and_window_functions.sql** – For SQL aggregation and ranking (Task 2).
- **index_performance.md** – For index performance testing (Task 3).
- **optimization_report.md** and **perfomance.sql** – For query optimization and analysis (Task 4).
- **partitioning.sql** and **partition_performance.md** – For table partitioning and performance improvement (Task 5).
- **performance_monitoring.md** – For ongoing performance tracking (Task 6).
